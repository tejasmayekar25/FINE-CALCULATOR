# 💰 Fine Calculator

Fine Calculator is a simple web application that helps users manage their monthly finances. It allows users to add daily expenses, calculate loan EMI, track monthly income, view spending through charts, and export financial reports as CSV files.

This project was created to practice front-end web development while building something useful for everyday budget management.


---

## 📖 How to Use

1. Add your daily expenses.
2. Enter your loan details and calculate EMI.
3. Enter your monthly income.
4. View your remaining balance.
5. Check the charts to understand your spending.
6. Export your report as a CSV file.

**Balance Formula**

```
Remaining Balance = Monthly Income − (Expenses + EMI)
```
